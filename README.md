# Page Pilot - ein hilfreiches Alltags-Tool für Leseratten
Nutzer sollen mit dem Page Pilot ihre Bücherdaten speichern können, um jederzeit eine Übersicht und Erinnerung daran zu haben, welche Bücher sie bereits gelesen haben.
Ihre gelesenen Bücher können sie dann auch bewerten und auf dieser Basis die nächsten Buchempfehlungen bekommen.
Zudem können sie ihren Lesefortschritt tracken und so an Lesezielen dranbleiben.

Kernfunktionen zusammengefasst:
* Bücherübersicht: Speicherung von Daten wie Titel, Autor, Genre, Gesamtseitenzahl und Status (ungelesen, wird gelesen, beendet)
* Fortschrittsanzeige: Nutzer dokumentieren die gelesenen Seiten - es wird ein prozentualer Fortschritt berechnet und eine Restlesezeit geschätzt
* Buchbewertung: Beendete Bücher können auf einer 1 bis 5-Sterne Skala bewertet werden
* Buchempfehlungen: Auf Basis der Bewertungen werden neue Buchempfehlungen für die Nutzer ausgewählt
* Statistiken: Nutzer erhalten z.B. eine Übersicht über gesamt gelesene Bücher, Seiten, häufigstes Genre, Autoren-Ranking oder ähnliches
* Streak-Counter: An jedem Tag, an dem die Nutzer Lesefortschritte tracken, wird ein Streak aufrechterhalten, der die Nutzer zu Leseroutinen motivieren soll
